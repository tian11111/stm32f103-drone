# VOFA+ 波形与 PID 调参

固件使用 USART1（PA9 TX、PA10 RX），9600 波特率、8 数据位、无校验、1 停止位、无流控。蓝牙模块的串口参数也应一致；VOFA+ 选择该模块对应的串口。

## 1. 接收 FireWater 波形

1. 在 VOFA+ 中选择串口，设置为 **9600 / 8N1**。
2. 协议引擎选择 **firewater**，打开连接和数据解析。
3. 添加波形图，通过右键菜单把接收通道绑定到 Y 轴。

固件约每 50ms 尝试发送一帧，格式为：

```text
pid:50,0.00,1.25,-3.56,4.12
```

每帧实际以 CRLF（`\r\n`）结束。`pid:` 是 FireWater 的帧前缀，不会自动命名各个通道。五个数值保持原有顺序：

| VOFA 通道 | 建议名称 | 含义 |
| --- | --- | --- |
| I0 / 通道 0 | wave_ms | 每次发送函数调用累计 50 的计数，单位 ms |
| I1 / 通道 1 | PitchTarget | 目标俯仰角，单位 ° |
| I2 / 通道 2 | PitchActual | 实际俯仰角，单位 ° |
| I3 / 通道 3 | PitchAngleOut | 俯仰角度环输出，作为角速度内环的目标，单位 °/s |
| I4 / 通道 4 | Battery | 电池电压，单位 V |

先把 I1、I2 绑定在同一个波形图中，方便比较目标与实际俯仰角；I3、I4 可放到独立波形图。I0 是普通数值通道，不会自动成为 VOFA 的时间轴。

发送使用中断，串口忙时跳过本次帧，不阻塞姿态采样。因此波形可能缺点，I0 不是硬件采样时间戳，也不能据此认定精确采样频率。9600 波特率用于低速观察；本次保留原有五个通道，不承担高频控制环性能测量。

## 2. 配置 PID 滑条

VOFA+ 的接收协议与发送命令分别设置。发送命令选 **Str / ASCII**，使用 `%f` 浮点占位符。

以俯仰角度外环 Kp 为例：

1. 左侧新建一条命令，命名为 `PitchAngleKp`。
2. 切换为 Str 模式，命令内容填入 `[slider,AngleKp,%f]`。
3. 拖入 slider 控件，在右键菜单中把它绑定到这条命令。
4. 设置滑条范围、精度和初值；Kp 可先用 0～10、初值 2.85。Ki 可先用 0～0.02、初值 0.003，Kd 可先用 0～0.2、初值 0.048。这些范围只是控件配置起点，适合的值取决于机体。
5. 操作控件后，VOFA 会把 `%f` 替换为数值，例如实际发出 `[slider,AngleKp,2.850000]`。

命令包含结束符 `]`，无需额外添加换行。`%f` 应由已绑定的控件替换；在普通发送框里手动发送时，请直接填写具体数值。

全部 19 条控件模板如下。参数名区分大小写，命令中的逗号、冒号、方括号使用英文字符。

| 参数 | Str 命令模板 | 固件默认值 |
| --- | --- | --- |
| 俯仰角度 Kp | `[slider,AngleKp,%f]` | 2.85 |
| 俯仰角度 Ki | `[slider,AngleKi,%f]` | 0.003 |
| 俯仰角度 Kd | `[slider,AngleKd,%f]` | 0.048 |
| 俯仰角速度 Kp | `[slider,SpeedKp,%f]` | 4.0 |
| 俯仰角速度 Ki | `[slider,SpeedKi,%f]` | 0.0 |
| 俯仰角速度 Kd | `[slider,SpeedKd,%f]` | 0.025 |
| 横滚角度 Kp | `[slider,RollAKp,%f]` | 2.85 |
| 横滚角度 Ki | `[slider,RollAKi,%f]` | 0.003 |
| 横滚角度 Kd | `[slider,RollAKd,%f]` | 0.048 |
| 横滚角速度 Kp | `[slider,RollGKp,%f]` | 4.0 |
| 横滚角速度 Ki | `[slider,RollGKi,%f]` | 0.0 |
| 横滚角速度 Kd | `[slider,RollGKd,%f]` | 0.025 |
| 航向角度 Kp | `[slider,TurnKp,%f]` | 2.85 |
| 航向角度 Ki | `[slider,TurnKi,%f]` | 0.003 |
| 航向角度 Kd | `[slider,TurnKd,%f]` | 0.048 |
| 航向角速度 Kp | `[slider,YawGKp,%f]` | 4.0 |
| 航向角速度 Ki | `[slider,YawGKi,%f]` | 0.0 |
| 航向角速度 Kd | `[slider,YawGKd,%f]` | 0.025 |
| 俯仰机械零点，单位 ° | `[slider,Offset,%f]` | 0.0 |

当前波形观察的是俯仰轴；三轴的参数均可按上表修改。

## 3. 手动发送与生效规则

手动发送下面任意一条，均可修改对应参数：

```text
[slider,AngleKp,3.20]
```

```text
[slider,AngleKi,0.003]
```

```text
[slider,Offset,-1.25]
```

也可使用旧 SET 命令，一次修改俯仰角度外环的 P/I/D：

```text
[SETP:2.85,I:0.003,D:0.048]
```

SET 支持省略字段，例如 `[SETI:0.003]` 只修改 Ki。合法字段分别生效，非法字段保持原值；它不是整组提交的事务。

固件也接受无方括号、以真实 LF 或 CRLF 结束的命令，例如 `slider,AngleKp,3.20` 后发送换行。直接发送字符 `\n` 不能代替换行字节。

- 合法参数在主循环处理命令时写入 RAM，随后的 PID 计算使用新值；重启后恢复代码中的默认值。
- 非数字、NaN、无穷大和浮点溢出值会被忽略。固件不限制有限值的调参范围。
- 参数没有确认回包或读取回包；本版本也不包含保存到 Flash 的命令。
- 接收端只保留一条待处理命令。逐条发送，建议操作/发送间隔至少 100ms，避免连续发送整批命令造成丢失。
- 指令缓冲区最多 99 字节；VOFA 控件中的 `%f` 模板均在此范围内。

## 4. 上板核对

拆桨完成以下核对：打开串口后应持续看到 `pid:` 开头且五列数值完整的帧；I1/I2 能显示两条曲线；发送单条调参指令后观察响应。需要确认具体参数已写入时，可用调试器查看上表对应的 PID 全局变量；本版本不回显参数。

本次软件验证覆盖帧内容、19 个参数映射、非法输入、串口错误恢复及发送忙时的缓冲区保持。VOFA 客户端控件绑定与真实蓝牙链路仍需按以上步骤验证；本文提供命令模板和绑定步骤，不是 VOFA 工程导入文件。

参考：[FireWater 官方格式](https://www.vofa.plus/docs/learning/dataengines/firewater)、[VOFA 命令与参数占位符](https://www.vofa.plus/docs/learning/start/data_cmd_parameter)。FireWater 官方允许省略前缀和冒号，真正的换行是必需的。
