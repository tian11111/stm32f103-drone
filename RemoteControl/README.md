# 遥控器

按 KEY9 在摇杆页和数据回传页之间切换。两页首行左侧均显示飞控上报的 `LOCK`（锁定）、`UNLOCK`（解锁）或 `UNKNOWN`（未知）；右侧 `Sig` 仍表示最近 10 次发送的成功次数。其余行显示 Pitch、前两路 PWM，以及沿用 `Spd` 标签的 Roll 和电池电压。

开机先显示 `UNKNOWN`，收到新状态后更新，切页保留未过期的状态。新遥控器在控制帧 `[6]` 设置 `0xA5`，使新飞控在两页均回传；旧飞控仅回传页应答。超过 1000 ms 没有有效状态时恢复 `UNKNOWN`；旧版飞控未提供状态、未知编码或通信中断也显示 `UNKNOWN`。状态来自 32 字节、类型为 `0x02` 的遥测帧：字节 `[3]` 的 `0xA1` 表示锁定，`0xA2` 表示解锁，其他值表示未知。显示仅反映收到的遥测，不是解锁命令或独立的安全联锁。回传没有序号，切页时在途旧帧可能短暂显示旧状态；超过 1 秒没有有效回传后恢复未知。拆桨/电机断电条件下已实测两页锁定、解锁切换、摇杆显示和飞控断电后的未知状态。
